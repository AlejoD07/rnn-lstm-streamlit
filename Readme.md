\# Clasificación de Secuencias con LSTM y Streamlit



Proyecto de Deep Learning que implementa una Red Neuronal Recurrente (Bidirectional LSTM) para el análisis de polaridad y sentimientos sobre texto secuencial (Dataset IMDb), con interfaz interactiva desarrollada en Streamlit.



\## Contenido del Repositorio

\- `notebook\_rnn\_experimentacion.ipynb`: Cuaderno de Google Colab con el EDA, preprocesamiento de secuencias, arquitectura recurrente, entrenamiento, curvas y matrices de evaluación.

\- `app.py`: Aplicación web interactiva.

\- `modelo\_lstm.keras`: Modelo recurrente entrenado.

\- `word\_index.json`: Diccionario de tokenización para inferencia en tiempo real.

\- `requirements.txt`: Dependencias del sistema.
